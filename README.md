# Hi, I'm Weida 👋

I'm a PhD candidate in Theoretical and Computational Chemistry
at The Chinese University of Hong Kong.

My research focuses on computational modeling, numerical
simulations, and quantitative analysis. I enjoy breaking down
complex problems, testing assumptions, and developing
computational tools to explore and understand data.

Beyond my doctoral research, I work on personal Python
projects involving machine learning, optimization, graph
algorithms, and data visualization.

## Selected Projects

### Machine Learning & Data Analysis

**[Through the Ages — Image Recognition & Data Pipeline](https://github.com/weida-feng/Through-the-Ages-Image-Recognition)**

A Python workflow combining PCA/KNN image recognition,
data validation, and statistical analysis of 14,557
historical game records.

### Numerical Optimization

**[CMA-ES Water Geometry Optimization](https://github.com/weida-feng/CMAES-Water-Optimization)**

Molecular geometry optimization using CMA-ES and
quantum chemical energy calculations, with experiments
exploring coordinate representations and model reliability.

### Graph Algorithms

**[Hong Kong Metro Route Analysis](https://github.com/weida-feng/Hong-Kong-Metro-Route-Analysis)**

Modeling the Hong Kong metro network with NetworkX,
comparing routes under different optimization objectives,
and visualizing network structure.

### Data Visualization & Applications

**[EU4 Trade Visualizer](https://github.com/weida-feng/EU4-Trade-Visualizer)**

A Streamlit application for parsing and visualizing
trade networks from Europa Universalis IV save files.

**[Guess the Country](https://github.com/weida-feng/Guess-the-Country)**

An interactive geography quiz built with Python and
Streamlit, featuring multilingual support.
